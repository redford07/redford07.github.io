3D portfolio adaptation for Kim WooChan

Reference: https://henryheffernan.com/
Original 3D environment, baked textures, and Draco decoder files:
https://github.com/henryjeff/portfolio-website
Copyright 2024 Henry Heffernan. MIT license: LICENSE-Henry-Heffernan.txt
The camera positions and monitor placement are adapted from that project's
CameraKeyframes.ts, BakedModel.ts, and MonitorScreen.ts.

Three.js 0.137.5 and its GLTFLoader, DRACOLoader, OrbitControls and CSS3DRenderer:
https://github.com/mrdoob/three.js/tree/r137
MIT license: LICENSE-three.txt
Local imports in the example modules were adjusted to use three.module.js.

Draco geometry decoder: https://github.com/google/draco
Copyright Google. Apache License 2.0: LICENSE-Draco.txt

Portfolio text and project/award photographs come from this repository's save.html.
content.js is a snapshot of those sections, not a live dependency on save.html.
The desktop UI and integration were implemented specifically for this portfolio.

Run from the repository root with: python -m http.server 8000
Then open http://localhost:8000/index.html
The 3D ES modules and model loaders require HTTP(S).
retro_desktop.html also works directly from the filesystem.
